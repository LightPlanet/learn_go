
1. Что такое frontend-разработка и чем она отличается от backend-разработки?
    * Frontend - GUI, как правило легковесный клиент. Backend - общение с базой данных, бизнес логика.
2. Какие основные технологии используются для создания интерфейса веб-сайта или приложения?
    * Языки: HTML, CSS, JavaScript.
    * Chromium - движок браузера, среда выполнения web.
    * V8 - движок JS.
    * WebGL - как OpenGL, только для Web и на JS, а не на C. Аппаратно укоренный рендеринг на GPU, шейдеры.
    * WebAssembly - позволяет компилировать программы на C, C++, Rust, Go под браузер, как под самостоятельную платформу.
3. Можешь ли ты назвать популярные языки программирования или инструменты, которые используют frontend-разработчики?
    * Фреймворки - React, Electron, Tauri. Языки разметки - HTML (Web), XML (например Windows Forms, C# WPF).
    * Любой(?) язык общего назначения: Python (библиотека tkinter), C++ (фреймворк Qt, библиотека ImGui), C (библиотека microui).
4. Что такое HTML, CSS и JavaScript, и какую роль они играют в создании веб-страниц?
    * HTML - язык разметки.
    * CSS - язык для описания стилей.
    * JavaScript - используется для анимаций, взаимодействия с элементами страницы (document.GetElementById("...")). Возможно создание полноценной реактивной модели программирования (React). Можно сказать, что это язык общего назначения, только для среды chromium (например Фабрис Беллар, создатель FFMPEG, разработал JSLinux - эмулятор x86 компьютера).
5. Какие задачи обычно решает frontend-разработчик при создании сайта или приложения?
    * Создание легко воспринимаемого, интуитивно понятного интерфейса.
    * Создание постоянной однообразной темы (стиля)
    * Обработка действий пользователя
    * Взаимодействие с бекэндом
6. Что такое адаптивный дизайн и почему он важен для frontend-разработки?
    * Пользователь должен иметь возможность использовать веб-приложение с любого устройства (телефон, ПК, ...)
    * Отдельные элементы (изображения, мат. формулы) должны легко читаться при любом масштабировании
7. Объяснить, что такое пользовательский интерфейс (UI) и пользовательский опыт (UX)?
    * UI - кнопки, надписи, выпадающие списки, поля ввода
    * UX - то, как чувствуется ваш интерфейс для пользователя
8. Какие современные фреймворки или библиотеки используются в frontend-разработке (например, React, Angular, Vue)?
    * Next.js, Svelte, SolidJS, Electron, Tauri.
9. Чем отличается статическая страница от динамической? Как это связано с работой frontend-разработчика?
    * Статическая - готовый HTML. Динамическая - генерируемый HTML, сервер подставляет данные из БД, API.\
    * Frontend-разработчик проектирует стратегию рендеринга.
10. Какие навыки или знания считаются обязательными для успешной работы в роли frontend-разработчика?
    * HTML5, CSS3, JavaScript ES6+, Git

# Git
### Основные команды  
`git add <path>` Добавить каталог (рекурсивно) в индекс для последующего коммита.  
`git status` Состояние файлов в рабочем каталоге (индексируемых и нет).  
`git diff` Посмотреть разницу между двумя Git деревьями (по умолчанию - между текущей копией и индексом, `git diff branch1 branch2` - между двумя коммитами).  
`git difftool` Запускает внешнюю утилиту для просмотра различий (VS Code, MSVC, ...).  
`git commit` Сделать коммит (локально). `git commit -m "Message" -S"` - коммит с сообщением и подписью.  
`git reset` Отмена изменений. Можно использовать для прерывания слияния.  
`git rm` Удаление файлов из индекса и рабочей папки.  
`git mv` Перемещение с автоматиеским удалением старого пути из индекса и добавления нового.  
`git clean` Удаление мусора (например, бинарные файлы) из рабочего каталога  

### Дополнительно  
`git commit -a` Позволяет пропустить `git add` и добавить все изменения в рабочей директории в коммит  
Файл `.gitignore` позволяет явно указать, какие файлы/директории/типы файлов нужно игнорировать.
